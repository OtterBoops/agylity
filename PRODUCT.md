# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Self-hosted engineering and homelab operators managing autonomous Google Antigravity coding agents, task swarms, and background routines across git repositories.

## Product Purpose

Agylity provides continuous Antigravity quota monitoring, rate-limit sentry protection, scheduled background task routines, and autonomous swarm dispatch orchestration with real-time telemetry.

## Positioning

A lightweight, non-invasive telemetry sentry and coordinator that communicates directly with Antigravity's local language server JSON-RPC socket, paired with a high-density, real-time reactive dashboard.

## Operating Context

- Single-tenant homelab deployment (`ottbox:5007`, `localhost:5173`).
- Docker containerized backend with SQLite state store and Discord notification dispatch.
- Vite + Preact + Tailwind CSS single-page frontend.

## Capabilities and Constraints

- Capabilities: Live quota telemetry polling, quota exhaustion alarms, task queueing and dispatching, prompt execution audit logs, routine cron scheduling, and connection inspector.
- Constraints: Single-tenant authenticated gate, zero emoji spam in telemetry, mobile-first responsive grid hierarchy, fixed container-scroll architecture.

## Brand Commitments

- Engineering aesthetic: High-density, precise telemetry, Pine-inspired palette (pine-base, pine-surface, pine-rose, pine-pine), monospace data readouts, compact status pills.
- Voice: Technical, concise, anti-sycophantic, zero decorative fluff.

## Product Principles

1. Telemetry Integrity: Display exact quota exhaustion and rate-limit states with deterministic timestamps; never mask or simulate synthetic stats.
2. Operator First: High information density, instant responsiveness, zero redundant duplicate views.
3. Clean Isolation: Strict separation of concerns between quota monitoring, task execution backlog, and system alerts.
